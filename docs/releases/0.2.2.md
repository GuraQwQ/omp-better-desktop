# Better OMP Desktop 0.2.2

Windows x64 正式发行，内置 OMP 18.12.6 运行时。

## 提供商与模型

- 新增 OpenAI 兼容、Anthropic 兼容两个自定义提供商模板，支持 Chat Completions、Responses 与 Messages 协议。
- 地址和凭据就绪后自动获取常见模型目录，支持端点回退、分页和一键填入当前分组。模型 ID 也可手工编辑。
- 配置写入 OMP 原生文件，保留其他提供商和已有模型参数；密钥不回显，留空可保留已保存值。
- 显示 CLI 接管状态。保存后新连接读取配置，进行中的任务继续完成。

## 实时反馈与会话交互

- 活跃工具调用右侧以“·”分隔显示实时生成速率，与输入栏共享 OMP 原生采样；暂时失败可恢复，连续失败逐步退避。
- 引导消息插入后，仍按实际工具调用保留速率关联和改动归属。审阅面板可以选择用户回合，查看已记录的文件操作。
- 队列消息可取回文本及附件，并保留已有草稿；取回与发送互斥。同文待发消息合并为数量摘要，每次取回一条。
- 输入 `@` 搜索项目 Git 文件，用方向键及 Enter/Tab 插入路径，支持中文和空格。
- 修正后台任务的消息传递模式，并串行更新同一标签的发行草稿附件。

## 安装与升级

下载 `Better-OMP-Desktop_0.2.2_windows-x64.exe` 安装。升级前结束正在运行的任务和终端，保留原数据目录。

安装器未签名，Windows 可能提示发布者未知。需要系统已有 WebView2，或自行配置 Fixed Version WebView2。安装、数据迁移与恢复步骤见[安装文档](https://github.com/GuraQwQ/omp-better-desktop/blob/main/docs/install.md)。

本次构建与验证由 GitHub Actions 执行。回合审阅基于已加载的真实工具记录，尚不提供文件系统检查点。
