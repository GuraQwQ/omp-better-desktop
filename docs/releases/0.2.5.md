# Better OMP Desktop 0.2.5

Windows x64 正式发行，内置 OMP 18.12.6 及匹配的桌面补丁。

## 进阶上下文与实际请求

- 会话用量面板右下角新增“进阶”，可查看当前系统提示词、完整 RPC 会话消息、工具定义与参数 schema、模型和思考级别等运行信息。
- 原文与 JSON 按需展开并支持复制，关闭或切换会话会丢弃过期读取，折叠内容按需挂载。
- “设置 → 进阶”新增实际请求捕获，默认关闭，下一次请求生效。可查看全局或当前会话的请求，并集中清空记录。
- 捕获复用 OMP 的 HTTP 发送层，记录发送前完成转换与注入的输入；认证头和 URL 凭据会脱敏，消息正文与附件保留。记录仅存本机，保留最近 7 天、最多 100 条、总计不超过 64 MiB。
- 当前会话快照无法还原已结束轮次的临时提示词覆盖，历史日志也不包含完整有效上下文。实际请求捕获只能看到客户端发出的内容，无法查看远端网关或模型服务端随后追加的提示词。

## 会话与文件交互修复

- 修复新会话尚未保存时，提供商配置更新后选择模型可能提示找不到文件的问题；改善连接恢复和模型菜单的加载、失败状态。
- 发送回执只清理对应的草稿快照，等待期间继续输入、重新输入同样文字或添加附件时保留后续编辑。
- 修复重复加载历史、乱序响应以及旧文件预览覆盖新项目的问题。
- 支持没有 Git 的项目文件列表，尊重忽略规则；工作区差异限定当前项目。
- 合并同帧流式事件，避免每个文本片段重复处理完整历史；历史摘要和分页索引使用有界缓存。

## 数据、运行时与构建

- 数据迁入区分完整成功、源文件仍在变化和冲突，展示实际复制数量，支持沿原来源重试。
- 同一安装包重启时保留手动导入或回退的运行时，随包运行时变化时再激活新包；旧选择器可重复迁移。
- 修正解包安装脚本的运行时目录；构建中断或回滚失败时保留恢复文件，下次构建先恢复。
- 修复上游更新 CI 对候选检出的复用方式，避免递归创建构建检出目录。

## 安装与升级

下载 `Better-OMP-Desktop_0.2.5_windows-x64.exe` 安装。升级前结束正在运行的任务和终端，继续使用原数据目录。

安装器未签名，Windows 可能提示发布者未知。需要系统已有 WebView2，或自行配置 Fixed Version WebView2。安装、数据迁移与恢复步骤见[安装文档](https://github.com/GuraQwQ/omp-better-desktop/blob/main/docs/install.md)。

发布构建与协议检查由 GitHub Actions 执行。本地已验证桌面交互与实际 OMP 二进制的本机 HTTP 回环，捕获正文与模拟服务收到的正文一致；未调用云端模型。
