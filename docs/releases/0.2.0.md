# Better OMP Desktop 0.2.0

Windows x64 发行包，内置匹配的 OMP 18.12.6 运行时。

## 界面与交互

- 沿用对话主轴：左侧项目与会话、中央消息与输入，需要时展开右侧改动。窄窗口中的审阅面板临时展开，保留正文阅读空间。
- 连续工具动作收为可展开的步骤摘要；读取、修改、命令和其他动作整行可点，保留小箭头提示状态。
- 读取展开真实路径和行号；修改展开各文件差异与错误；命令展开退出码与输出。原始 JSON 入口继续保留。
- 审阅面板按行显示差异，长代码行可以横向滚动。
- 回复直接呈现正文，复制操作放在消息下方。
- 工具、思考、调用参数、差异和图片在展开后才挂载；收起保持紧凑间距并释放重内容。较长工具序列拆成多个小组，保留虚拟列表的作用范围。
- 上下文、剩余容量、累计用量和缓存命中继续显示，点击可展开统计分桶；统计按会话隔离。

## OMP 原生速率

模型与思考程度旁显示 OMP 的平滑生成速率。计数来自引擎已有的模型 tokenizer；输出结束后按用量校准，样本不足时显示空值。历史会话只显示本次应用已记录的原生读数，查看它们不会启动新的 OMP 进程。

速率采样使用独立的小 RPC 响应，不反复获取系统提示和工具声明；界面显示速率不代表减少模型 token。

## 安装和升级

下载 `Better-OMP-Desktop_0.2.0_windows-x64.exe` 与 `SHA256SUMS`，核对 SHA-256 后安装。升级前结束正在运行的任务和终端，并保留原数据目录；应用启动时校验新运行时，保留上一份托管运行时用于回退。程序目录与数据目录仍分别管理。

安装器未签名，Windows 可能提示发布者未知。需要已有 WebView2，或自行配置 Fixed Version WebView2。完整步骤与数据恢复说明见[安装文档](https://github.com/GuraQwQ/omp-better-desktop/blob/main/docs/install.md)。

当前发行仅覆盖 Windows x64。第三方自定义 TUI、登录提供商和外部服务的边界见[上游集成说明](https://github.com/GuraQwQ/omp-better-desktop/blob/main/docs/upstream.md)。
