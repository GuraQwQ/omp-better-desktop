# Better OMP Desktop 0.3.0

Windows x64 正式发行，内置 OMP 18.14.1 及匹配的桌面补丁。

## 界面与轻量动效

- 标题栏与工作区操作合为一行，收敛间距、字号和圆角，调整窄窗口布局。
- 弹层、对话框与错误提示增加纯 CSS 入场动效，遵循系统“减少动态效果”设置；错误提示改为悬浮展示。
- Markdown 独立加载，缩小首屏主包；消息复制增加成功反馈，代码块支持一键复制。
- 首帧前使用本机主题缓存，减少页面加载时的主题跳变。

## 对话与键盘操作

- 切换会话时恢复阅读位置，发送后回到最新消息；离开底部后显示简洁的“回到最新”按钮。
- 压缩、重试等等待状态显示动态标签、用时和持续进行提示。
- 命令面板支持方向键和 Enter 选择，并处理输入法组合输入。
- Esc 可中止当前任务，空输入框按方向键上取回上一条用户消息。
- 消息轮数与操作按钮同排，悬停时显示；可在外观设置中关闭轮数。

## 会话分组与后台提醒

- 保存的会话按本地日期分为今天、昨天、过去 7 天及更早，更早的记录默认折叠。
- 后台任务完成后在侧栏显示未读圆点，需要处理的问题优先显示；回到当前会话后清除完成标记。
- 窗口失焦时，超过 15 秒的任务完成或需要确认、输入时发送系统通知；短任务或无法发送通知时使用任务栏提醒。
- 原生通知异步发送失败也会回退到任务栏提醒，本地日期分组按日历计算，覆盖夏令时边界。
- 外观设置新增“后台完成时通知”开关，默认开启。通知可用性受 Windows 通知设置影响，点击通知暂不承诺定位对应会话。

## 上游自动构建

- 修复上游 RPC 源码变化导致桌面补丁无法应用的问题，减少补丁中的生成代码，由上游生成器统一生成协议与各语言客户端。
- 运行时升级到 OMP 18.14.1，移除已由上游支持的密码输入字段补丁。
- 按上游新的组件目录合并代理和原生组件的第三方许可材料，修复运行时打包路径。
- 同步 OMP 的构建包仍公开为 Pre-release，成功发布后仅保留最新预览；正式版发行历史保留。

## 安装与升级

下载 `Better-OMP-Desktop_0.3.0_windows-x64.exe` 安装。升级前结束正在运行的任务和终端，保留原数据目录。

安装器未签名，Windows 可能提示发布者未知。需要系统已有 WebView2，或自行配置 Fixed Version WebView2。安装、数据迁移与恢复步骤见[安装文档](https://github.com/GuraQwQ/omp-better-desktop/blob/main/docs/install.md)。

正式安装包由 GitHub Actions 构建并进行协议、类型和编译检查。交互夹具和本机配置保留在忽略目录，不随仓库发布；未调用云端模型。
