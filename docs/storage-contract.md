# 数据与运行时契约

`src-tauri/src/storage.rs` 管理数据根下的运行时、迁移日志与 CLI 接管；`bootstrap.rs` 在创建 WebView 前确定根目录并配置运行时。宿主在迁移、切换运行时和清理时持有数据操作锁，并要求活动会话与终端先关闭。

## 运行时

运行时包包含 `runtime-manifest.json`，字段为 `{version,revision,protocolVersion,executable,files:[{path,sha256}]}`，发行包另含 `patchDigest`。支持实际请求捕获的包声明 `requestCaptureVersion: 1`。路径相对于包目录，清单包含可执行文件和许可材料。安装逐项校验路径、文件唯一性与哈希，以兼容信息和文件内容确定安装标识。

包复制到独立的 `runtimes/<id>`，使用进行中标记记录未完成安装；成功后写入 `runtime.json` 当前与前一个版本选择器。重复安装会校验并复用相同内容，部分完成可以重试，旧版本供回退使用。托管运行时的协议必须与桌面期望一致。

选择器同时记录已处理的随包运行时 `lastBundled`。同一安装包再次启动保留用户手动导入或回退的有效选择；安装包携带新运行时后才激活新版本。旧选择器首次迁移保留已有有效选择并记录随包身份，重复执行保持一致；当前项损坏或安装未完成时恢复随包版本，保留有效的上一项。

## 历史读取缓存

历史摘要与分页索引以文件路径、大小和修改时间识别版本，外部追加或改写后重新读取；目录扫描移除已删除日志的缓存。摘要上限 4096 条，详细索引上限 8 份且合计原日志大小不超过 16 MiB，超过 30 分钟未使用即过期。大日志不进入详细缓存，分页只返回当前页。设置中的缓存清理同时释放本数据根的历史缓存。

## 请求捕获缓存

`request-capture.json` 保存默认关闭的诊断开关，运行时在每次发送请求前读取，不需要停止对话。记录位于 `cache/request-captures/<desktopSessionId>/<requestId>.json`，以临时文件写入后逐文件重命名；同会话的元数据关联实际历史路径。列表可按当前宿主会话 ID 或规范化后的历史路径筛选，重启后仍可查找保留记录。

保留最近 7 天、最多 100 条且总计不超过 64 MiB 的请求，写入和查询时清理超限记录；未完成写入超过 30 分钟可回收。单条正文超过容量上限时只保留元数据和无法捕获的原因。设置中的“清空请求记录”可重复执行，仅逐文件删除本功能管理的记录；全局缓存清理也包含该目录。

## OMP 数据

托管 OMP 用户根为 `<dataRoot>/omp`，宿主通过 `OMP_USER_ROOT` 传给 GUI RPC 与 CLI 子进程。应用数据根还包含桌面配置、浏览器数据与临时缓存。外部原始 OMP 目录只用于发现和导入。

导入按文件记录路径与摘要，不把凭据内容写入日志；SQLite 使用备份接口复制一致性快照，源数据保留。迁移日志让重复执行跳过已处理文件，同时保留导入后的本地修改。

CLI 接管通过独立 shim 传入托管用户根，并在每次调用时解析当前运行时选择器；撤销接管恢复原调用路径。用户 shell profile 不用于存放接管脚本。

安装与恢复操作见 [安装说明](install.md)。
